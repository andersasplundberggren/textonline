🔍 Apps Script Diagnostik

Detta verktyg hjälper dig att testa din Google Apps Script-anslutning.

📋 Instruktioner

  1. Kontrollera att din Apps Script URL är korrekt ovan
  2. Klicka på "Test getSettings" för att hämta inställningar
  3. Om du får JSON-data = Fungerar!
  4. Om du får fel = Följ felsökningsstegen nedan

⚠️ Vanliga problem

404 Error: Apps Script är inte korrekt publicerat
  • Gå till Deploy → Manage deployments
  • Kontrollera att "Who has access" är satt till "Anyone"
"Unexpected token <": Får HTML istället för JSON
  • Apps Script kräver inloggning (fel inställning)
  • Kontrollera "Who has access" = Anyone
CORS Error: Blockerat av webbläsaren
  • Apps Script måste vara korrekt publicerat
  • Testa URL:en direkt i en ny flik först
